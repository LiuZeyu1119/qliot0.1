## 交给人工实测的最小清单

1. 设置 `QLIOT_TEST_SERIAL_PC` 和 `QLIOT_TEST_SERIAL_SENSOR` 后运行 com0com 定长帧、文本帧和 F405 流程测试。
2. 接入目标 Modbus 从站后，确认不同固件版本的处理时间、主动上报和异常码。
3. 选定 TDMS 读取策略后，用原 LabVIEW 数据文件对比行列、单位、曲线点数。
4. 连接真实传感器后，核对 `AT,set,meastart`、`AT,get,stringdata`、`AT,get,spec` 的回包和超时行为。
5. 用 LabVIEW 前面板人工核对 Qt 主界面控件位置、隐藏状态、默认值和每个按钮的业务动作。
