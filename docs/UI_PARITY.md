## 当前 Qt UI 范围

- 主界面：LabVIEW 风格蓝色外框，左侧设备配置表/设备库/串口侧栏，右侧主 Tab。
- 主 Tab：测试数据、设备配置、设备标定、总线设备/网关。
- 测试数据页：顶部接收/剩余字长区、测量数据表、右侧最新值列表、自绘曲线、曲线选择。
- 设备配置页：MCU、LoRa、DTU 基本配置和写入按钮。
- 设备标定页：标定点表、曲线名、测量值、标定值、温度和增删改保存按钮。
- 总线设备/网关页：总线设备列表、总线管理、DTU 网络、AT 管理器。

## 后续像素级还原任务

1. 将 461 项 Controls/Indicators 分批定位到 Qt Widgets。
2. 对照 LabVIEW 截图校正每组控件位置、宽高、颜色、字体、Tab 层级。
3. 为隐藏控件和状态对象继续建立 Qt 状态映射。
4. 真实硬件联调后复核每个按钮的设备侧副作用。

## 2026-07-02 可见主界面重排

本轮参考 LabVIEW 主前面板的可见操作区完成对比。对比截图仅作为本地临时调试产物，验证后清理，不纳入仓库。

已调整：

1. 主界面从“顶部串口工具条 + 三栏 splitter”改为 LabVIEW 风格的蓝色外框。
2. 左上常驻 `设备配置表`，左下常驻 `设备库` 树，左下右侧放串口连接/协议/波特率/从站 ID/开始区域。
3. 右侧主 Tab 固定为 `测试数据`、`设备配置`、`设备标定`、`总线设备/网关`，位置从整屏 Tab 改为参考图中的右侧 Tab 区。
4. `测试数据` 页按参考图重排：顶部接收/剩余字长，中部测量数据表和右侧列表，下部数据曲线。
5. 修正 `AppConfig`、设备表、测量表、虚拟设备消息和曲线控件中的中文编码污染。

本次继续补齐：

1. `设备配置表` 示例数据扩展到参考图可见的 11 行，并压缩表格行高以贴近 LabVIEW 网格。
2. `测试数据` 顶部接收/剩余字长控件改为固定宽度行，右侧最新值列表补齐青色状态框和 `0` 数值框。
3. `设备标定` 页接入独立 `CalibrationTableModel`，不再复用测试数据表。
4. `总线设备/网关` 页接入 `BusDeviceTableModel`，默认不写入测试应答码。
5. `串口连接` 区接入 `SerialSession` 和异步通信控制器，实际执行 AT、DTU、Modbus 扫描、参数读写和测量，不模拟连接或回包。
6. 底部日志区已移除，状态消息改为非模态弹窗。
7. 当前 Qt 界面已完成截图复核；临时截图已在验证后清理。

仍需人工或后续迭代校准：

1. LabVIEW 截图里存在大量前面板隐藏/引用控件，当前仅还原用户主操作区，隐藏状态对象后续逐批迁移。
2. 右侧三个非当前页 Tab 已接入可用模型和参数组，但像素级位置仍需用 LabVIEW 前面板逐项核对。
3. LabVIEW 前面板没有直接导出每个控件坐标，精确像素需在 LabVIEW 内人工核对。
4. 当前使用 Qt Widgets 原生控件近似 LabVIEW 外观，边框、滚动条和系统标题栏与 LabVIEW 仍会存在平台差异。
