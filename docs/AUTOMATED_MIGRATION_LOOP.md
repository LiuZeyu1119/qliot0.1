# 自动迁移循环

## 循环目标

每轮迁移必须按固定顺序执行：

1. 计划：从 `docs/labview-analysis` 的官方证据选取一个可验证功能片段。
2. 编程：只改该片段需要的 Qt 模块，不批量乱改。
3. 测试：优先用虚拟设备和 QtTest 验证；真实硬件不可用时写入待办。
4. 记录：更新需求追踪矩阵、构建验证记录和待办。
